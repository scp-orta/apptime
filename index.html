Sitenize nasıl eklersiniz?

Doğrulamayı sunucu tarafında yapın. Secret key tarayıcıya gönderilmemelidir.

// Kendi sunucunuzda (Node.js örneği)
const r = await fetch("https://createapp-three.vercel.app/api/verify", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    secretKey: process.env.BOT_SECRET_KEY,
    webKey: kullaniciningWebKeyi
  })
});
const { valid, name } = await r.json();
